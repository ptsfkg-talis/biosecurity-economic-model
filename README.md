# Biosecurity Economic Efficiency Calculator

Інтерактивна вебмодель для оцінювання економічної ефективності заходів біологічної безпеки в районах підтоплення.

## Що є в програмі
- 10 базових заходів;
- редагування витрат `C_i`;
- редагування імовірності ризику `P_i`;
- редагування 5 складових потенційних збитків;
- автоматичний розрахунок `L_i`;
- автоматичний розрахунок `E_i` за 4 експертними критеріями;
- автоматичний розрахунок `AL_i`, `Ef_i`, `EE_i`;
- сценарії: низький / базовий / високий ризик;
- графік економічної ефективності;
- рейтинг заходів;
- збереження сценарію в браузері;
- експорт результатів у CSV.

## Формули
- `L_i = L_ms + L_ec + L_se + L_vet + L_inf`
- `E_i = (b1 + b2 + b3 + b4) / 20`
- `AL_i = P_i × L_i × E_i`
- `Ef_i = AL_i − C_i`
- `EE_i = Ef_i / C_i`

## Експертні критерії E_i
1. Ступінь зниження біологічного ризику
2. Швидкість досягнення ефекту
3. Масштаб охоплення
4. Стійкість результату

Кожний критерій оцінюється від 1 до 5 балів.

## Сценарії ризику
- Низький: базове `P_i × 0.75`
- Базовий: без змін
- Високий: базове `P_i × 1.20`, але не більше 1.00

## Публікація через GitHub Pages
1. Створіть новий репозиторій, наприклад `biosecurity-model`.
2. Завантажте `index.html` і `README.md` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У **Build and deployment** виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`.
6. Натисніть **Save**.
7. GitHub покаже адресу опублікованого сайту.

## Примітка
Базові числові значення мають сценарний характер. Для наукового використання їх слід замінювати або верифікувати статистичними, експертними чи нормативними даними.
